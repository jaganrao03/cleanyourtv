# jaganrao03/cleanyourtv — personal fork

Fork of [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv) (MIT) used to run an
Apple-TV-style home on a Chromecast with Google TV.

The work in this fork is the tvOS-style polish pass: home screen redesign, a working control
centre that opens the real vendor settings screens, and a wallpaper picker that decodes off the
main thread. Details, screenshots and the engineering notes live in
[docs/tvos-polish/README.md](docs/tvos-polish/README.md).

Branch: `tvos-polish`. `main` tracks upstream and is kept unmodified so `git rebase upstream/main`
stays clean.
